# 遗境 · 逃亡 — RELIC RUN

可在浏览器中游玩的古代丛林神庙无尽跑酷游戏。第三人称后方追踪、真实 3D 蒙皮人物、键盘与触屏操作；正式游戏在首段 20 秒之后继续生成道路。

当前内容对应画面与动作第五次修订版。纯静态网站，无需构建、账户、服务端或在线素材接口。网站首页即 [游戏入口](index.html)。

发布仓库：[xhuozhong/relic-run](https://github.com/xhuozhong/relic-run)。在线地址：[https://xhuozhong.github.io/relic-run/](https://xhuozhong.github.io/relic-run/)；该地址在 GitHub Pages 首次部署成功后启用。

## 玩法

- 首段依次经历奔跑、跳跃、右转、滑行、石板松动、向右闪避和继续逃亡。
- 7 类机关与 6 组组合，202 米之后的布局每次重新排列。
- 藤蔓回廊、瀑布廊桥、祭火遗庭连续交替；危险路线提供更多金币和可跳跃收集的遗物。
- 正式逃亡到达 202 / 562 / 922 米后解锁对应区域练习。暂停或结束时可以返回起点选择。
- 浏览器本地保存最远距离、最高分和单次遗物纪录；练习不覆盖正式纪录。

## 操作

| 动作 | 键盘 | 触屏 |
|---|---|---|
| 跳跃 | ↑ / W / 空格 | 向上滑 |
| 滑行 | ↓ / S | 向下滑 |
| 换道；临近拐角时转弯 | ← → / A D | 左右滑 |
| 暂停 / 继续 | P / Esc | 轻触画面，按继续 |
| 开关声音 | M | — |

“开始逃亡”由玩家操作；“观看 20 秒玩法演示”为自动演示。观察喷火冷却和巨石摆动，选择安全路线。连续碰撞会使追兵逼近；掉入断桥、坍塌道路或漏转会结束本轮。

## 本地预览

需要现代浏览器和 WebGL。安装 Node.js 后，在仓库目录运行：

```sh
node server.cjs
```

然后打开终端显示的本机地址。默认端口为 4173，也可使用 `node server.cjs 4180` 指定端口。浏览器直接双击本仓库的 HTML 可能因本地文件访问限制而无法载入 3D 资源，应使用静态服务器。

## 在线部署

所有资源使用相对路径，可部署到 GitHub Pages 的仓库子路径，也可放入普通静态网站空间。GitHub Pages 设置中选择 **Deploy from a branch → main → / (root)**；仓库包含 `.nojekyll`，无需安装依赖或执行构建。部署完成后的 Pages 地址就是在线游戏。

更新时同步源码及 `assets/`，避免只上传首页。完整网站约 58 MiB，首次访问需要下载运行资源；后续缓存行为由托管服务与浏览器决定。

## 画面与性能边界

人物为真实 3D，使用已适配的 CMU 跑步动捕和 Quaternius 动作。桥面、机关与雕塑为 3D；部分塔门立面、植物、远景和追兵使用图像素材。当前没有达到参考图片的摄影级真实度，也不能从背面参考证明正脸完全一致。

本机 Edge / Intel Iris Xe 的第五版测试约 59.8–60.0fps；竖屏数据来自电脑视口模拟，未经实体手机验证。这不是所有设备或所有帧达到 60fps 的保证；网络首次载入时间与游戏运行帧率是不同指标。

运行 `node verify.cjs` 可检查脚本语法、运行资源是否齐全、人物的内嵌资源和五个动作；更新文件后用 `node verify.cjs --manifest` 刷新发布清单。此静态检查不能替代实际浏览器操作测试。
